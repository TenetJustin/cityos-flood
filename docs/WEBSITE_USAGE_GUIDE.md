# CITY OS 深圳全灾害指挥中心 —— 网站功能使用指南

> 版本：v5（P1-A 版）｜更新：2026-09｜范围：本仓库 `frontend/`（React）+ `backend/`（FastAPI）全栈
> 研究演示原型，不替代正式预警。数据缺失/后端离线时各页自动降级（回退样本/空卡），不白屏。

## 0. 快速开始（部署与启动）

前置：Node.js ≥ 18、Python 3.10+、现代浏览器（SWE 页需 WebGPU；无 GPU 可用 Chrome SwiftShader 回退）。

```bash
# 后端（端口 8000）
cd backend && python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --port 8000 &

# 前端（开发模式，端口 5173；vite 代理 /api → 8000）
cd frontend && npm install && npm run dev
# 浏览器打开 http://localhost:5173

# 生产构建（产物 dist/，静态托管 + /api 同源或反代）
cd frontend && npm run build
```

**顶栏**：左侧 «» 收展侧栏；中间品牌"深圳全自然灾害指挥中心 v5"；右侧实时点（**绿=实时数据在线**、灰=回退样本）、时钟、☀/☾ 深浅主题切换。
**侧栏脚注**：平台五大能力（守恒状态空间+本体脆弱性+反事实+EnSRF+CEM），并声明"研究演示原型，不替代正式预警"。

## 2. SWE 物理引擎页（🌊 重点页面）

福田区二维浅水方程（SWE）WebGPU 实时推演：**降雨 → 地表积水 → 道路/设施影响（行为链）**。
数值内核：三角非结构网格 KP central-upwind；守恒量 η-hu-hv；Manning 摩擦；排水三件套。
**推演结果供物理引擎演示与量级对照，不做逐格精确预报（逐格校验待 LarNO 地理锚定）。**

### 2.1 SWE 控制区（页面左栏）

| 控件 | 作用 |
|---|---|
| **网格** 下拉 | `60 m（61k tri）`＝P0 验证网格；`30 m 全分辨率（247k tri）`＝NASADEM 原分辨率。切换会重建引擎并重置推演。 |
| **雨型** 下拉 | 恒定强度（默认，配滑杆）或历史真实暴雨事件（CHIRPS 日雨→设计雨型时程）：`2014-05-11 特大暴雨`（169 mm）、`2023-09-07 台风暴雨`（97 mm）、`2018-08-30 暴雨`（65 mm）。 |
| **雨强滑杆** 0–150 mm/h | 恒定雨强（仅"恒定强度"时生效），步长 5。 |
| **倍速滑杆** 1–64× | 模拟加速倍率（仅影响推演速度，不影响物理）。 |
| **排水开关 ☑** | 排水总开关（三件套）：(a) 管网排水＝LarNO 77 场退水中位 1.47%/5min 标定容量场×建成度（derived）；(b) 海/河出口＝深圳湾低岸弛豫 τ600s；(c) 山溪坑＝bed>8m 深洼 τ900s。**关闭＝全蓄型上界（积水量偏大）；开=现实下界，两组对比即排水影响。** |
| **开始/暂停** | 实时推演（帧循环；stats 持续更新）。 |
| **湖静止自检** | 铺 0.1m 静水 200 物理秒验证格式 well-balanced（漂移≈0 才说明内核正确）。**先跑它再降雨。** |
| **重置干燥** | 清空水体。 |
| **⛈ 推演历史暴雨事件 (6h)** | 选事件后一键跑完整 6 小时（72×5min 子步分块，右下状态显示进度）。 |
| **推演结果 → 行为链** | 把当前积水推给后端行为层 → 下方"积水→行为链"区显示各区受影响人口/被困/孤岛。 |

### 2.2 读数（右栏实时 stats）
模拟时刻（h）· 积水总量（万 m³）· 积水面积 km²/109.9 km²（含 >5cm、>15cm 子面积）· 最大水深与**稳健 p90 水深**（对照以 p90/>15cm 面积为准——30m 网格 max 可能被谷底单点伪影拉高）· 最大流速。画布点击可看选中三角编号（调试用）。

### 2.3 建议操作流程
1. 网格选 60m 熟悉 → 换 30m 正式对比；2.「湖静止自检」drift≈0；3. 先关排水跑一组（上界）、再开排水跑一组（下界）对比积水面积；4. 选历史事件→「⛈ 推演历史暴雨事件 (6h)」；5. 读 p90/>15cm 面积；6.「推演结果→行为链」看区级影响（罗湖/福田受影响人口）。

### 2.4 LarNO 域级对照（折叠面板）
后端 `/api/larno/summary`：LarNO（MIKE+ 真实福田管网 20m 基准，77 场）中位 **峰值水深 2.293 m / >15cm 面积 3.6 km² / 退水 1.47%/5min**——本引擎排水容量即以该退水中位标定（derived，诚实标注）。逐格面积重合/时序指标待 A2 锚定（backend/scripts/larno_compare.py 已就绪）。

### 2.5 脚注数值口径（诚实框定，页面原文）
湖静止 200s drift≈0（CPU f64 0 / GPU f32 0）；600s 50mm/h 质量误差 CPU −2e-7 / GPU f32 −2.2%（单精度守恒损失）；排水关 6h 均强 >15cm 6.9 km² vs LarNO 5.2 km²（偏高~40%，wall 上界）；排水开（30m 事件 20140511 169mm）>15cm 15.1 km²、p90 0.54m（LarNO 中位~3.6 km²，无溪线/蓄滞→保守偏大~3×，逐格不可比）。

## 3. 态势总览页（overview）

- **实时告警流**：critical/warning/info 分级流动条；🔇 可静音（记住）；critical 发声提示；SSE 推送即刷。入口行有「⟳ 立即刷新」。
- **今日态势简报**：LLM 文字简报；「告警详情是什么？」等快捷问题点击即跳到知识库城安助手并预填。
- **四灾种实时卡**：台风/内涝/滑坡/风暴潮 状态（正常→危险）+ 风速/最不利区/隐患点数/增水。
- **内涝概率桶**：各区分位水深区间（P10–P90）+ P50 中位线。
- **排水恢复观测**：148 站严重度×退水速度（删失标注）。
- **福田物理基准 LarNO**：80 场 MIKE+ 基准事件散点+中位峰值水深/退水速率。
- **高温/大雾/雷电卡**：气候风险预警区数。
- **居民影响小卡**：当前内涝情景 4 指标+主导行为（无积水提示去详情页）。
- **2D/3D 地图**：右上切换。3D：城市实景，图层可叠建筑/灾种点/台风云带/降雨粒子/洪水演进；视角预设 全景/市中心/俯视/低空；活跃台风路径叠加。2D：指标切换（P50 水深/超15cm 概率/本底脆弱性）+ 叠加层开关（500m 精细格、水网 OSM、管网-合成、井/泵/涝点、78 泵站），近似/合成图层有文字提示。
- **三联预测曲线**：降雨/内涝峰值/风速（过去 6h+未来 48h，"现在"参考线）；下行滑坡日演进概率（AUC 0.821 标注）+ 内涝分区峰值 TOP。
- **风暴潮面板**：站点切换；天文潮/总水位双曲线；关注/警戒/严重阈值线。
- **数据口径表**（SOURCE_TABLE 折叠）：各图层来源与免责声明；每 5 分钟自动刷新。

## 4. 世界模型推演页（world）

- 守恒状态空间世界模型说明卡（方程与质量守恒声明）。
- ① **分区积水轨迹**：各区分时集合中位水深曲线。
- ② **空间耦合表**：区↔区关联（假设边/水动力边/设施接入/格点映射）+ provenance。
- ③ **道路损伤·动态可达性**：可达人口占比 KPI + 分区损伤条。
- ④ **反事实干预**：输入「封路：罗湖,福田」/「抽排增效：南山:1.5」→「运行反事实」→ 基线/干预后/Δ 可达性（台风页复用）。
- ⑤ **数据同化 EnSRF**：选行政区+观测水深(m)+注入时刻(h)→「注入观测」→ 同化前后轨迹对比、创新残差、集合均值/方差；数据不足给横幅。

## 5. 自主优化 WAM 页（wam）

- 需有效预报运行号（过期禁用并提示等待）。参数：滚动时域（12–72h）· 目标偏好（均衡/生命安全优先/能耗约束）· CEM 搜索预算（快速/标准/稳健）→「运行安全动作优化」。
- 结果（**建议式，不下发 SCADA**）：6 段决策流程条 + W-S-A-R 契约卡；① 基线 vs 优化指标（峰值 P50/超 15cm 概率/可达性/综合代价）；② 奖励分解条形（正值=较基线减代价）；③ 安全投影（建议/修正/可行/硬约束违例）；④ 逐区动作表（请求倍率→安全投影→审批状态）；⑤ AUDIT 证据链。
- 「📋 提交为决策建议」→ 决策队列人工审批。折叠区：技术栈 7 步上线纪律 Roadmap（数据尚不满足 RL 训练，诚实声明）。

## 6. 居民影响与行为页（human-impact）

- 顶部灾种 chip（内涝/台风/地震/高温/滑坡/风暴潮/山洪）+ **情景滑杆**：震级 M5–8、48h 降雨 80–400mm、风速、体感、增水（合成情景，明示"用于推演演示"）。
- **灾后时间线**：T0…T+n 时相按钮（默认 T+6h）。
- **四指标卡**：受影响/出行受阻/关键服务受损人口 + 预计恢复时间。
- **热图**：Leaflet 逐点按影响评分分色，悬浮看强度/人口/出行·医疗·避难影响（人口底 GHS 栅格）。
- 右栏：行为分布（主导+占比）、影响分解（5 加权分项 0–100）、区级排名。脚注：行为/恢复阈值 = assumed 参数。

## 7. 台风页（typhoon）

- 路径库列表（点击看路径）：名称/季节/级别/距深最近距离与时刻/峰值风速/最低气压/末 8 路径点。
- 主图 3D 路径叠加 + 链式预测（CascadePanel：台风→风→雨→内涝/滑坡的 ML 级联）。
- **反事实 What-if**：6 种预设情景/自定义 → 三情景对比（台风页与总览页复用）。

## 8. 风暴潮页（surge）

- 潮位站汇总（HKO 谐波天文潮基准、最大/平均天文潮、潮差、位置）。
- 48h 天文潮/总水位双曲线 + 关注/警戒/严重阈值线（/api/surge/live?hours=48）。
- 四大历史事件（含山竹，最大波高 9.51m 注释）近岸点（大鹏湾口/珠江口/深圳湾）波高柱状对比。

## 9. 滑坡页（landslide）

- 预警卡（隐患点总数、历史发布次数）+ 各分区隐患点柱状（红色=高风险）。
- 3D 隐患点分布（叠加地形与建筑）；明细表可按分区/街道过滤（位置/坡度/坡高/易发性/风险）。
- 敏感性曲线（/api/ml/landslide-sensitivity）。

## 10. 地震页（earthquake）

- USGS 真实地震目录（震级≥4.5、400km 内、近 120 天）。
- 断裂带列表（性质/长度/备注）。
- **情景评估**：震级滑杆 M4–8（每动即重查）→ 破坏半径（≥Ⅵ 烈度）、各分区烈度/震中距/影响；react-leaflet MMI 烈度图。
- 区级风险分级（/api/earthquake/risk）。

## 11. 水库与山洪页（reservoir）

- 水库清单/蓄洪余量、预泄方案（/api/reservoirs/*）。
- **48h 降雨滑杆 0–400mm**：拉动即重算下游河道与山洪沟道联合预警（绿/黄/橙/红四级）。

## 12. 沉淀知识库页（knowledge）

5 个 Tab：
- **真实案例**：按领域过滤，案例档案含当时已知（真实观测）/关键未知项/官方级别/演示在用。
- **历史事件**、**城市底座**（数据底座索引）、**模型**（模型档案）。
- **城安助手**（assistant）：RAG 问答（POST /api/knowledge/ask），支持从总览页简报问题跳转预填。
- 内嵌 FloodProfilePanel（典型淹没过程档案）。
