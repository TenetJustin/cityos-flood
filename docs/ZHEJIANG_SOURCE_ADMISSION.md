## 温州已公开下载样本：通过可访问性，不通过空间/时效质量门槛

2026-10-20 对三个温州官方目录页及两份可公开下载的 CSV 压缩包进行只读核查。下载响应确认无需 API 密钥即可取到当前公开文件；门户“完全开放”分类不等同于明确的开放许可证，具体再利用条款仍须核对。

| 来源 | 本次样本检查 | 可用边界 |
|---|---|---|
| [市区易涝点信息](https://data.wenzhou.gov.cn/jdop_front/detail/data.do?iid=6478) | 门户显示 181 条、2017 年至今、完全开放；字段仅标识码、名称、时间 | 无经纬度、积水深度或独立事件记录，不能空间化或用作积水真值 |
| [瑞安市水旱灾害雨情信息](https://data.wenzhou.gov.cn/jdop_front/detail/data.do?iid=11666) | 公开 CSV 导出 800,000/4,247,498 条；GB18030；221 个站码；样本时间 2023-09-01 00:05 至 2023-09-14 00:35；观测重复键（站码+时间）0；数值雨量范围 0–7.5；导出中的异常标记 800,000 条全为“无记录” | 门户时间范围标注 2000 年至今，但当前下载受 800,000 条上限截断且仅含 13 天；无站点名称/坐标，雨量单位和采样时长未给出，目录更新周期为每年。不能当作四城覆盖或实时雨量 |
| [温州水文河道水情信息](https://data.wenzhou.gov.cn/jdop_front/detail/data.do?iid=6352) | 公开 CSV 导出 800,000/1,922,000 条；GB18030；263 个站码；样本时间 2015-08-19 10:20 至 2019-09-23 14:15；观测重复键（站码+时间）0；`Z` 数值范围 -1.87–779.51，其中 5.03% 大于 100、0.97% 小于 0 | 无站点坐标、单位、垂直基准和质量字段；这些数值不能据此判为错误，也不能作物理解释。仅作质量待核的历史河道水位候选，不用于模型或潮位边界 |

尝试对温州另一个[测站信息工程信息目录](https://data.wenzhou.gov.cn/jdop_front/detail/data.do?iid=8205)作站点交叉映射时，页面显示数据量为 0，且同时出现“完全开放”和“受限开放”标记，因此无法补齐位置/高程基准。历史河道数值需要数据提供方确认单位、垂直基准、站码元数据与质量码后再评估。

2026-10-20 核对温州市公共数据开放平台的三个**接口目录页**，并未取得接口响应或使用许可，故不得计入四城实测覆盖率：

| 目录 | 字段及空间粒度 | 页面宣称的更新周期 | 关键阻断 |
|---|---|---|---|
| [浙江省级区县面雨量小时实况信息](https://data.wenzhou.gov.cn/jdop_front/detail/api.do?iid=16966) | `City`、`County`、`Observtimes`、`Value`；区县面雨量，不是街道站点或积水深度 | 小时级 | 必须注册、创建应用、申请并获批；数值单位、累计时窗、实际 `available_at` 和再利用许可未从目录确认 |
| [小时雨量信息（瑞安市）](https://data.wenzhou.gov.cn/jdop_front/detail/api.do?iid=13200) | `STCD`、`RAIN`、`ENDTM`；瑞安站点，不能代称温州市区 | 每半年 | 同样需审核；目录的“小时雨量”字段不等于实时更新，站点位置和质量码未确认 |

三个页面都显示请求样例需 `appsecret`，并写明申请审核流程。未经凭据与许可，不抓取预览或绕过授权；获批后先取两个不同日期的样本，核对字段、单位、观测时窗、站点位置、质量和响应延迟，再决定能否进入自动刷新或历史回放。

## 下一次准入的最低条件

1. 先拿到可以重复请求的真实样本，以及该样本对应的版本/许可证明；不能以宣传页代替数据。
2. 每条数值保留 `evidence_type`、`observed_at` 或预报的 `issued_at`/`valid_at`、实际 `available_at`、`retrieved_at`、时区、单位、CRS/垂直基准、来源 URL/版本、质量标记与显式缺失。
3. 用两个不同日期和四城各一个空间样本核对字段、单位、时序、断流和异常；实际可获得时间无法证明时写 `null`，不得进入 as-of 回测。
4. 降水模式、卫星估计、站点观测和历史最佳路径分层显示；它们不能互相冒充，也不能单独校准城市积水或居民响应。
5. 通过质量门槛后才接入自动刷新；先对每个来源单独展示健康、延迟和覆盖率，再允许进入组合分析。

当前无需专属城市权限的天气预报链路已通过 ECMWF 样本接入；NASA IMERG 卫星估计仍需账号与现行下载接口。两者都**不替代**街道级实测积水、潮河水位、排水资产和独立影响真值。
