# 五城数据源与事件候选登记（C2）

更新日期：2026-10-19。适用城市：上海、宁波、福州、深圳、海口。

本文只登记已经定位到的来源和候选事件，不表示项目已经取得原始数据，也不授予任何
记录以观测真值、回测输入、公众预警或自动调度资格。事件不限于台风；只要存在可核对
的极端降雨、潮位、河流顶托或其复合作用，均可进入候选筛选。

## 1. 状态与晋级规则

来源和事件必须按下列顺序晋级，不得跳级：

`discovered → access_confirmed → acquired → structurally_valid → source_reviewed → locked_backtest`

- `discovered`：确认发布者和稳定引用；只可作为获取线索。
- `access_confirmed`：确认实际下载/申请方式及适用许可；仍未取得数据。
- `acquired`：原件进入项目外部只读数据目录，并记录取得时间和校验值。
- `structurally_valid`：通过 manifest、时间、单位、空间和缺失规则；不表示来源真实。
- `source_reviewed`：人工核对发布主体、原件、许可、站点/仪器和质量说明。
- `locked_backtest`：冻结事件、预报快照、输入血缘和评估规则，可进入独立回测。

当前没有任何五城事件达到 `locked_backtest`。

## 4. 数据质量最小检查集

每个取得的数据集在进入事件 manifest 前至少执行：

1. **粒度**：明确一行是站点—时刻、网格—时刻、道路—时刻还是事后汇总；禁止混粒度拼接。
2. **唯一性**：检查源记录 ID，以及事件、现象、站点/区域、观测时刻、版本的复合键。
3. **双时间**：分别保存 `observed_at` 和真实 `available_at`；网页发布时间、项目下载时间不得相互替代。
4. **空间**：保存源坐标、CRS、空间分辨率；GCJ-02/BD-09 不得标成 EPSG:4326。
5. **高程**：潮位、河水位和积水深度保存垂直基准、零点和转换方法；未知基准不做跨站比较。
6. **单位**：保留源单位；转换生成新记录，不覆盖原值。
7. **质量与缺失**：保留原始 QC 标记、迟到数据、订正版本和缺测原因；`0` 不当作缺失。
8. **许可**：记录数据集级许可、允许用途和再分发条件；网页可读不等于可提交原始数据。
9. **泄漏**：最佳路径、再分析、事后订正和灾后统计不得进入当时可见输入。
10. **回测资格**：只有来源复核后的有限数值观测可作真值；政府总结、新闻稿和部门复盘均为 `historical_record`。

| P0 | 取得深圳“9·7”当时签发的预报快照及逐站观测 | 气象/水务数据授权或公开档案 | 每个预报版本有 `issued_at` 和输入血缘 |
| P1 | 核对宁波水文、潮位、积水和巨灾水位桩资料 | 水利、住建、保险资料的使用许可 | 观测与理赔/历史记录严格分层 |
| P1 | 继续筛选海口实际城市内涝事件 | 海南气象、水务、住建/城管和交通原始记录 | 至少找到一个有降雨实况和积水时空记录的候选事件 |

时只记录 `access_restricted` 或 `not_acquired`，不使用合成数据补齐真实事件包。
